# ICT Scanner Telegram Bot\n\nPrototype Telegram alert bot scanning Gold futures proxy (GC=F), BTCUSD, EURUSD and GBPUSD using a simplified 5-minute liquidity-sweep + displacement + FVG rule.\n\n## Required secret\n\nSet `BOT_TOKEN` in the hosting platform's environment/secrets. Do not commit the bot token. Optional `CHAT_ID` sends alerts to a fixed chat; otherwise users can interact with the bot and `/start`, `/status`, `/scan`.\n\n## Run\n\n`python main.py`\n\nNo third-party Python packages are required (Python 3.9+; Python 3.10+ recommended for `zoneinfo`).\n\n## Important\n\nThis is an experimental signal alert prototype, not an official complete implementation of all ICT models and not financial advice. Yahoo Finance data can be delayed/unavailable. `GC=F` is a Gold futures proxy, not spot XAUUSD. TP/SL tracking uses candle high/low and can be ambiguous if both are touched in the same candle.\n
